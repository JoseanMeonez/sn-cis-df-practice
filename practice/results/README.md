# Quiz Results Archive

This folder contains all completed quiz and practice test results.

## File Naming Convention

| Type | Format | Example |
|------|--------|---------|
| Topic Quiz | `{domain}-{YYYYMMDD-HHMMSS}.md` | `configuration-20260120-143022.md` |
| Practice Test | `practice-test-{YYYYMMDD-HHMMSS}.md` | `practice-test-20260120-160000.md` |

## How to Use These Files

1. **Review Past Performance**: Open any file to see your answers and scores
2. **Track Progress**: Compare scores across multiple attempts
3. **Identify Patterns**: Find topics you consistently struggle with
4. **Study Guide**: Use incorrect answers as a focused study guide

## Commands

- `"Show my quiz history"` - List all quizzes in this folder
- `"Review {filename}"` - Get detailed analysis of a specific quiz
