## Configuration Management Database (CMDB)

Use the ServiceNow® Configuration Management Database (CMDB)
application to build logical representations of assets, services, and the
relationships between them that comprise the infrastructure of your
organization. Details about these components are stored in the CMDB as
configuration items (CIs) which you can use to monitor the infrastructure,
helping ensure integrity, stability, and continuous service operation.

Overview

Use core features such as CMDB Health, CMDB Identification and
Reconciliation, and CMDB Data Manager to monitor and detect health
issues, reconcile data integrity issues, and manage data life cycle.

Note:   CMDB modules, features, and wizards are not supported
on mobile devices. You cannot use a mobile device to access the
CI Class Manager, Query Builder, or Duplicate CI Remediator or
to access or configure CMDB features such as Identification and
Reconciliation, CMDB Health, CMDB Data Manager, baseline CMDB,
and proposed changes.
